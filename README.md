# 羽球對決 2.5D 🏸

網頁版 2.5D 羽球遊戲：**左手搖桿移動、右手按住蓄力、往方向划動出拍**。目前可以單打對 AI，線上房間開發中。

## 怎麼玩

| | 手機（橫放） | 電腦 | 手把 |
|---|---|---|---|
| 移動 | 左半邊螢幕按住拖曳 | WASD | 左搖桿 |
| 蓄力 | 右半邊螢幕按住 | 滑鼠按住／空白鍵 | RT |
| 出拍 | 往方向划 | 拖曳滑鼠／方向鍵 | 右搖桿撥出去 |
| 取消（假動作） | 不划直接放開 | 不拖直接放開 | 放開 RT |

划動方向決定球種（遊戲會依擊球點高低自動判斷）：

| 擊球點 | ↑ 上划 | ↓ 下划 | ← → 橫划 |
|---|---|---|---|
| 高（頭頂） | 高遠球 | 蓄力多＝殺球、少＝切球 | 平高球／平抽 |
| 中 | 挑球 | 撲球／下壓／切球 | 平抽 |
| 低（低於網） | 挑球 | 放網／推球 | 平抽 |

蓄力決定「總擊球距離」：力道不足會掛網、太大會出界；離網越遠需要越多蓄力。斜著划可以控制落點左右。來球越快反彈力越大，接殺球時輕輕一划就能擋回網前。

## 開發

```bash
npm install
npm run dev        # http://localhost:5173/badmiton-project/
npm run build      # 輸出到 dist/
npx tsx scripts/sim-test.ts normal 80   # 無畫面測試：擊球求解器 + AI 對打統計
```

推到 `main` 會由 GitHub Actions 自動部署到 GitHub Pages。

## 程式結構

- `src/config.ts` — 球場尺寸、物理、手感參數（調手感改這裡）
- `src/sim/` — 遊戲邏輯，和畫面完全分開（之後線上對戰共用）
  - `physics.ts` 羽球空氣阻力物理、落點預測、擊球軌跡求解
  - `shots.ts` 划動方向 → 球種、蓄力 → 落點
  - `match.ts` 比賽規則：發球、得分、掛網、出界、局數
- `src/ai/ai.ts` — AI 對手（預測落點 → 跑位 → 選球 → 蓄力出拍），用跟玩家一樣的輸入
- `src/input/controls.ts` — 觸控雙搖桿／鍵鼠／手把
- `src/render/` — Three.js 畫面（球場、球員、羽球、影子、拖尾）
- `src/ui/hud.ts` — 記分板、蓄力條、球種文字
