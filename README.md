# 羽球對決 2.5D 🏸

網頁版 2.5D 羽球遊戲：**左手搖桿移動、右手按住蓄力、往方向划動出拍**。單打或雙打（你＋AI 夥伴）對 AI，或開線上好友房跟朋友對打。

## 怎麼玩

第一次玩建議先點選單的「新手教學」。

| | 手機（直向或橫向） | 電腦 | 手把 |
|---|---|---|---|
| 移動 | 左半邊螢幕按住拖曳 | WASD | 左搖桿 |
| 蓄力 | 右半邊螢幕按住 | 滑鼠按住／空白鍵 | RT |
| 出拍 | 往方向划 | 拖曳滑鼠／方向鍵 | 右搖桿撥出去 |
| 取消（假動作） | 不划直接放開 | 不拖直接放開 | 放開 RT |
| 跳殺 | 點一下再按住 | 連按兩下空白鍵／滑鼠 | 連按兩下 RT |

**跳殺**：連按兩下並按住後，高球（2.3 m 以上）快到時會自動起跳（`GAME.jump.lead` 調時機）；看到起跳後約 0.35 秒往下划，在最高點擊中最好。待命時腳下有青色小圈。跳殺時蓄力不會超過出界線。

**擊球回饋**：擊中後畫面停頓一下（殺球、跳殺更久）；評價 完美／不錯／勉強；揮空會顯示原因；球打過來時腳邊白圈是擊球範圍，變綠代表現在划剛好；發球時會畫出能站的發球區。

按下蓄力時會有圓環波紋、腳下光圈（蓄到出界區變紅）和短震動（Android；iPhone 不支援震動）。按下就立刻開始累積蓄力（`chargeDelay` = 0）。鏡頭角度在 `src/config.ts` 的 `CAMERA` 調整。

划動方向決定球種（遊戲會依擊球點高低自動判斷）：

| 擊球點 | ↑ 上划 | ↓ 下划 | ← → 橫划 |
|---|---|---|---|
| 高（頭頂） | 高遠球 | 蓄力多＝殺球、少＝切球 | 平高球／平抽 |
| 中 | 挑球 | 撲球／下壓／切球 | 平抽 |
| 低（低於網） | 挑球 | 放網／推球 | 平抽 |

蓄力決定落點深度：力道不足會掛網、太大會出界，好球區約佔蓄力條 75%，越靠近底線越難抓。斜著划可以控制落點左右。來球越快反彈力越大，接殺球時輕輕一划就能擋回網前。

球速：殺球、撲球、下壓維持原速；切球、放網、發小球快 1.2 倍；其他球快 1.5 倍（`src/config.ts` 的 `ballSpeedMul`）。初速有上限：殺球／平抽約 230 km/h（`smashMaxSpeed`）、高遠／挑球約 160 km/h（`liftMaxSpeed`）、網前撲球約 58 km/h（`killMaxSpeed`）。

## 球員、球拍、場地、模式

每位球員有特質、每支球拍有取捨（`src/sim/kits.ts`），兩者倍率相乘。「球速」是同一條軌跡飛得更快（不是打更遠）。對手每場隨機換球員和球拍。

| 球員 | 特質 |
|---|---|
| 全能型 | 標準 |
| 重砲手 | 殺球 +12%；跑速 -4%、起步 -6% |
| 網前魔術師 | 切球／放網 +3%、落點誤差 -15%；殺球 -6%、高遠 -5% |
| 推壓手 | 推球／平抽 +6%；高遠 -7% |
| 快腿 | 跑速 +5%、起步 +10%；殺球 -5%、推球 -3% |

| 球拍 | 取捨 |
|---|---|
| 均衡拍 | 標準 |
| 攻擊拍（頭重） | 殺球 +4%；落點誤差 +15% |
| 速度拍（頭輕） | 揮拍判定 +18%、推球 +5%；殺球 -3% |
| 控制拍 | 落點誤差 -30%；殺球 -5% |

- **場地**：櫻花園、夜櫻（燈籠與螢火蟲）、竹林、市場（條紋遮陽棚攤位、蔬果、紅燈籠與燈泡串、騎樓店面）、稻田（隨風一波波起伏的秧苗、倒映天空的水田、農舍、稻草人、白鷺）、海灘（左邊是海、右邊是沙灘：浪花進退、椰子樹、海灘傘、帆船、海鷗）、室內球館（`src/render/environment.ts`、`nightGarden.ts`、`market.ts`、`paddy.ts`、`beach.ts`，全部程序產生，樹會隨風搖）
- **角色外型**：每位球員有不同身高、髮型、頭帶、背號，球拍框顏色跟著球拍；揮拍有拖尾（殺球金色、跳殺青色）
- **自動跑位（預設）**：電腦幫你跑位，右邊擊球、左邊「撲」圈往方向划 = 魚躍（設定可改成手動跑位或電腦自動撲）。設定都在選單的「⚙ 設定」
- **魚躍撲救**：移動搖桿連按兩下再往某方向划（電腦：Shift + WASD；手把 B）→ 撲出約 1.7 m、擊球範圍往那個方向多 0.5 m、最高 1.5 m，撲到就自動救回網前（放網，撲的時候右手不用操作），之後趴 0.8 秒（`GAME.dive`）。AI 跑不到的低球也會撲（`diveRate`），`npx tsx scripts/dive-test.ts` 看統計
- **擊球時機 = 球質**：完美的高遠球落在底線前約 0.4 m，「不錯」短約 0.4–0.8 m，「勉強」掉到中場；放網／切球時機好就貼網又低（過網高度約 1.58 m），時機差就離網遠又高；殺球、平抽時機好更快。高遠球越短，對手殺球越快（最多 +10%，`GAME.attackSmashBonus`），AI 也越想殺
- **硬伸手接快球**：殺球、撲球、平抽打到離身體路線越遠，硬伸手接的球質越差（側向 0.7 m 內正常、0.9 m 開始變機會球、1.1 m 以上多半是機會球或掛網；`GAME.stretch`）。魚躍撲救不受影響、一定救得過網，AI 也會改用魚躍。`npx tsx scripts/stretch-test.ts` 看對照表
- **抓球**：中前場（離網 2.3–3.8 m）平飛過來、到網子高度以上的球「只點一下」（平球）→ 搶下來往下壓（`GAME.intercept`）。雙打：對手回的不是殺球（平球、小球、挑高）時維持前後站，前面的人站到約 2.1 m 封網、優先攔截撲／抓
- **球種說明**：設定、暫停畫面的「📖 球種說明」，依目前操作方式列出每種球的手勢與用途（`src/ui/guide.ts`）
- **網前撲球**：網前 2.3 m 內、球高於網時按平球（點一下／左右滑）→ 撲球，約 75 km/h（一般撲球 58），打向中場，反應快的對手約一半救得到（`GAME.netKill`）
- **手動跑位**擊球範圍 ×1.2（`GAME.manualReachMul`），自動跑位與 AI 維持原本
- **場館巡迴賽**：櫻花園站 → 竹林站 → 夜櫻站，每站兩位對手＋館主（`src/modes/tour.ts`）。AI 有打法個性：進攻型、網前型、防守型、平抽快攻、假動作大師（`STYLES` in `src/ai/ai.ts`），也會多打自己球員的強項
- **訓練關卡**：高遠球、殺球、網前、接殺、平抽、跳殺（`src/modes/drills.ts`）
- **雙打（對 AI）**：你＋AI 夥伴（近側）對兩位 AI，難度、分數、局數、場地、操作照設定；夥伴和對手每場隨機（夥伴至少「普通」）。你頭上有黃色箭頭、腳下黃圈；自己這隊穿你球員的球衣色（夥伴深一點），對手穿對比色（藍或紅）
  - 規則：雙打邊線（3.05 m）；發球要落在對角發球區（前發球線～雙打後發球線 5.94 m、雙打邊線內），只有對角的接發球員能接；每邊只能打一拍（打過的那隊兩人都要等對方回球）；落地得分制、比分以隊伍計
  - 發球輪轉（BWF）：發球方分數偶數從右區、奇數從左區發；發球方得分 → 同一人再發、和夥伴換左右；接發球方得分 → 換發球，大家都不換位，站在對的發球區的人發；新的一局由贏的那隊站右區的人先發
  - 分工（`src/ai/doubles.ts` 的 `ballTaker`）：對方每打一拍，就照預測軌跡算隊上誰「最早來得及」接，差不多時照陣型分（前後站：前場球給前面、後場球給後面；並排：球在誰那半邊誰接）。兩位 AI 和你的自動跑位用同一個結果，所以不會搶球也不會都放掉；手動跑位時比較靠近你的球，夥伴會讓給你（分到夥伴的球你腳下不會出現擊球範圍圈）
  - 陣型（`formationSpot`）：自己這隊往下壓（殺、切、放網、平抽、撲）或對方挑高 → 進攻前後站（前場約 2.35 m、後場約 4.6 m）；自己這隊挑高 → 防守左右並排（約 3.9 m 各顧半邊）；打完球回到陣型位置
  - 雙打 AI：落點打兩位對手中間或空檔；網前球高過網帶就撲；像點擊滑放一樣直接指定球種與深度（不用蓄力），誤差照難度。線上對戰只有單打
- **新手教學**（`src/modes/tutorial.ts`）：固定流程教每個搖桿與方向，球快到時暫停等玩家照提示操作，做錯重來；依目前的操作方式與跑位產生步驟。`npx tsx scripts/tutorial-test.ts` 無畫面跑完全部流程
- **平衡**：`npx tsx scripts/balance-test.ts` 跑 AI 對打勝率；目前每個球員×球拍組合對標準組合約 49–53.5%
- **動作**：程序化步法（`src/render/playerModel.ts`、`src/render/anim/`）：腳踩地不滑、併步、交叉步、弓箭步、分腿墊步、準備姿勢、轉身看球、跳殺剪刀腳

### 音效（`src/audio.ts`，全部即時合成，不用音檔）

- 擊球（拍線脆響＋軟木「啵」，殺球有爆裂感、完美有「叮」）、揮拍破風、掛網、落地、球鞋急停的吱吱聲、跳殺落地
- 觀眾掌聲（回合越長越熱烈）、裁判中文報分（瀏覽器內建語音，「5 比 3，局點」）
- **每個場地的音效都不同**（`PROFILES` in `src/audio.ts`）：
  - 空間感：室內球館大殘響＋預延遲；市場短殘響＋店面彈回來的回音；竹林柔而散；櫻花園／夜櫻乾淨；稻田、海灘最開闊幾乎沒有殘響
  - 腳下：室內運動地板吱吱叫最響；戶外球場墊的吱聲短而軟，加上鞋底磨到沙土的沙沙聲；落地聲有彈性木地板、空心木棧台（海灘）、悶悶的泥土（稻田、竹林）、紮實的水泥地（市場）
  - 觀眾：室內滿場掌聲＋歡呼＋口哨；市場攤販拍手、吆喝、敲鍋子；海灘一小群人拍手、手指口哨、「呼～」；稻田幾個農夫稀稀落落地拍；櫻花園／夜櫻有禮貌的輕拍；竹林兩三個人輕輕拍。輸分時有觀眾的地方會「唉～」
  - 得分提示音：記分板叮咚、小銅鈴（市場）、鋼鼓（海灘）、木魚（稻田）、撥弦（櫻花園／夜櫻）、竹筒（竹林）
- 場景環境音：櫻花園鳥叫、竹林風聲與竹子敲擊、夜櫻蟋蟀、市場人聲嘈雜／攤販吆喝／碗盤聲、稻田蛙鳴蟲鳴與微風、海灘一波波的浪聲與海鷗、室內觀眾席
- 背景音樂：五聲音階撥弦，依場地換音階與速度（櫻花園／夜櫻都節音階、竹林陽音階、室內明亮快板、市場宮調＋輪指、稻田小調慢板、海灘反拍刷弦），比賽中自動變小聲
- 選單可分別開關音效、音樂、裁判報分。iPhone 靜音鍵開著也會出聲（Safari 17+）

### 兩種擊球方式

- **蓄力划動**（預設）：右手按住蓄力、往方向划動出拍；點一下再按住 = 跳殺
- **點擊滑放**（不用蓄力）：右手按住往上滑放開 = 高遠球／挑球、往下 = 切球／放網（上手或下手依擊球點高低自動判斷：`autoDepth` in match.ts）；左右 = 平抽、只點不滑 = 平球（球快到身邊才出拍；網前高於網 = 撲球）；放開的那一刻出拍，放開時機決定球的品質。右手上方的「殺」搖桿：往下或左右滑放開 = 殺球（左右瞄準，前場自動撲球）、往上滑放開 = 假殺真切、只點不滑 = 直線殺球；點一下再按住 = 跳殺（電腦：空白鍵殺球）

## 線上對戰（好友房）

選單「線上對戰」→ 建立房間 → 把 4 碼房號或分享連結（`?room=房號`）傳給朋友。先進房的是房主，分數、局數、場地照房主的設定；雙方各用自己的球員、球拍、操作方式（可以一邊手動一邊自動跑位）。

- **伺服器**（`server/`）：Cloudflare Worker + Durable Object，一個房號一個物件，最多兩人，只轉送訊息、不跑遊戲邏輯（WebSocket Hibernation，免費方案就夠）
- **同步**（`src/net/sync.ts`）：兩邊各自模擬整場比賽、都把自己放在畫面下方（收到的座標 x、z 反號）
  - 自己的位置每秒送約 18 次，對方外插＋平滑
  - 擊球方送「擊球點＋初速」，對方從同一點發出（軌跡確定）再補上單程延遲（ping 量）
  - 每一球由**接球方**判定得分，擊球方等判定（`await` 階段），所以不會兩邊判得不一樣
  - 線上沒有擊中停頓（不然兩邊時間會越差越多）；暫停畫面時比賽照常進行
- **測試**：`npx tsx scripts/online-test.ts 60 3`（兩台假手機、單程 60 ms，加第三個參數 `drift` 模擬掉幀）；瀏覽器測本機伺服器：`cd server && npm run dev`，網址加 `?server=local`
- **部署伺服器**：`cd server && npx wrangler deploy`（要先 `npx wrangler login`）。改了訊息格式記得把 `src/net/protocol.ts` 的 `PROTOCOL` +1

## 開發

```bash
npm install
npm run dev        # http://localhost:5173/badmiton-project/
npm run build      # 輸出到 dist/
npx tsx scripts/sim-test.ts normal 80   # 無畫面測試：擊球求解器 + AI 對打統計
npx tsx scripts/doubles-test.ts normal 8 21   # 雙打：四個 AI 對打，檢查發球輪轉、對角接發、每邊一拍、雙打線、分工、陣型、勝率
```

推到 `main` 會由 GitHub Actions 自動部署到 GitHub Pages。

## 程式結構

- `src/config.ts` — 球場尺寸、物理、手感參數（調手感改這裡）
- `src/sim/` — 遊戲邏輯，和畫面完全分開（線上對戰兩邊各跑一份）
  - `physics.ts` 羽球空氣阻力物理、落點預測、擊球軌跡求解
  - `shots.ts` 划動方向 → 球種、蓄力 → 落點
  - `match.ts` 比賽規則：發球、得分、掛網、出界、局數；單打 2 人、雙打 4 人（`players[id]`，0、2 號近側一隊，1、3 號遠側一隊，隊伍 = `id % 2`；`score`／`games` 以隊伍為索引）
- `src/ai/ai.ts` — AI 對手（預測落點 → 跑位 → 選球 → 蓄力出拍），用跟玩家一樣的輸入
- `src/ai/doubles.ts` — 雙打分工（這球誰接）與陣型站位，AI 夥伴、AI 對手、玩家的自動跑位、畫面都用它
- `src/input/controls.ts` — 觸控雙搖桿／鍵鼠／手把
- `src/net/` — 線上對戰：`protocol.ts` 訊息格式、`sync.ts` 比賽同步、`room.ts` 房間連線與大廳
- `server/` — 房間伺服器（Cloudflare Worker）
- `src/render/` — Three.js 畫面（球場、球員、羽球、影子、拖尾）
- `src/ui/hud.ts` — 記分板、蓄力條、球種文字
