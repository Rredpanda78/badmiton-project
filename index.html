操作說明

手機（直向、橫向都可以）

  • 左手：螢幕左半邊按住拖曳 → 移動
  • 右手：螢幕右半邊按住 → 蓄力；往某方向划動 → 出拍
  • 按住後不划、直接放開 → 取消（可以當假動作）
  • 自動跑位：整個螢幕都是擊球區，只管擊球

擊球方式二：點擊滑放（不用蓄力）

  • 右手點一下按住 = 下手球：往上滑放開 = 挑球、往下滑放開 = 放小球
  • 右手點兩下按住 = 上手球：往上滑放開 = 高遠球、往下滑放開 = 切球
  • 左右滑放開 = 平抽
  • 右手上方的「殺」搖桿：往下或左右滑放開 = 殺球（左右決定落點；前場自動變撲球）；往上滑放開 = 假殺真切（切球）
  • 「殺」搖桿點一下再按住 = 跳殺：球快到時自動起跳，滯空時滑放開
  • 球的品質看放開的時機：腳邊圈圈變綠時放開最好
  • 跳殺：右手點一下再按住（連按兩下），高球快到時會自動起跳；看到起跳後約 0.35 秒往下划

划動方向

  • ↑ 上：高遠球（高點）／挑球（低點）
  • ↓ 下：蓄力多 = 殺球、少 = 切球；低於網子時 = 放網
  • ← → 橫：平抽；斜著划可以控制落點左右

蓄力條

  • 紅色下段 = 力道不足會掛網；紅色上段 = 出界
  • 綠色越深 = 越靠近底線的好球
  • 來球越快反彈力越大，接殺球輕輕一划就能擋回網前
  • 球打過來時腳邊的白圈 = 擊球範圍，變綠色就是現在划剛好
  • 擊球會顯示評價（完美／不錯／勉強），揮空會告訴你原因（太早／太晚／太遠／太高）

電腦／手把

  • WASD 移動；滑鼠按住蓄力、拖曳出拍（或 空白鍵蓄力 + 方向鍵出拍）
  • 手把：左搖桿移動、RT 蓄力、右搖桿撥出去出拍
