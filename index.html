操作說明

手機（直向、橫向都可以）

  • 第一次玩建議先跑一次新手教學
  • 開始比賽後選單打／雙打、難度（簡單～地獄）、場地、分數、局數，還有你和對手的球衣顏色
  • 預設自動跑位：電腦幫你跑位，右手只管擊球
  • 右手（預設：點擊滑放）：按住往上／下／左右滑、放開出拍；上手或下手依球的高低自動判斷；右上「殺」搖桿殺球
  • 時機：放開得越準（完美），高遠球越貼底線、小球越貼網、殺球越快；高遠球不到位，對手殺得更兇
  • 網前撲球：對手的小球放太高、球在網前高於網時，點一下（平球）或左右滑 = 撲球
  • 左手：橘色「撲」圈往球的方向划 = 魚躍撲救，撲到會自動救回網前；撲完要趴一下才爬得起來
  • 手動跑位（設定裡切換）：左邊變成移動搖桿；移動搖桿連按兩下（圈變橘色）再划 = 魚躍

擊球方式二：點擊滑放（不用蓄力）

  • 右手按住 → 往上滑放開 = 高遠球（後場高球）／挑球（網前低球）
  • 右手按住 → 往下滑放開 = 切球（後場高球）／放小球（網前低球）
  • 左右滑放開 = 平抽；只點不滑（球到身邊時點一下）= 平球
  • 右手上方的「殺」搖桿：往下或左右滑放開 = 殺球（左右決定落點；前場自動變撲球）；往上滑放開 = 假殺真切（切球）；只點不滑 = 直線殺球
  • 「殺」搖桿點一下再按住 = 跳殺：球快到時自動起跳，滯空時滑放開
  • 球的品質看放開的時機：腳邊圈圈變綠時放開最好

划動方向

  • ↑ 上：高遠球（高點）／挑球（低點）
  • ↓ 下：蓄力多 = 殺球、少 = 切球；低於網子時 = 放網
  • ← → 橫：平抽；斜著划可以控制落點左右

蓄力條

  • 紅色下段 = 力道不足會掛網；紅色上段 = 出界
  • 綠色越深 = 越靠近底線的好球
  • 來球越快反彈力越大，接殺球輕輕一划就能擋回網前
  • 球打過來時腳邊的白圈 = 擊球範圍，變綠色就是現在划剛好
  • 擊球會顯示評價（完美／不錯／勉強），揮空會告訴你原因（太早／太晚／太遠／太高）

雙打（開始比賽 → 模式選「雙打」）

  • 你＋AI 夥伴對兩位 AI；頭上有黃色箭頭的是你，夥伴穿你的顏色深一點的球衣，對手兩人穿對手顏色
  • 每邊只能打一拍；電腦會決定這球誰接（腳下出現擊球範圍圈 = 你的球），沒輪到你就讓夥伴打
  • 用雙打邊線；發球要發到對角、不能超過雙打後發球線；發球方得分就換左右區再發

線上對戰

  • 建立房間後把房號或分享連結傳給朋友，朋友輸入房號或點連結就會進房
  • 分數、局數、場地照房主上次在「比賽設定」選的；球員、球拍、操作方式各用自己的
  • 右下角是連線延遲；暫停時比賽不會停

電腦／手把

  • 點擊滑放：滑鼠左鍵按住拖曳放開 = 擊球（同右手搖桿）；右鍵按住拖曳放開 = 「殺」搖桿（只點 = 直線殺球、連按兩下右鍵 = 跳殺）；空白鍵 = 直線殺球
  • 蓄力划動：WASD 移動；滑鼠按住蓄力、拖曳出拍（或 空白鍵蓄力 + 方向鍵出拍）
  • Shift + WASD 方向 = 魚躍撲救；手把 B 鍵
  • 手把：左搖桿移動、RT 蓄力、右搖桿撥出去出拍

設定

操作

自動：電腦幫你跑；對手出拍時左手往你猜的方向按住拖，猜對立刻起步、猜錯慢一步。輔助：自己推搖桿，方向差不多電腦就幫你對準、打完自動回位。手動：全部自己跑（擊球範圍最大）。

魚躍：自動跑位時左邊「撲」圈往球的方向快速一划；輔助／手動時移動搖桿連按兩下再划。撲出去會自動把球救回網前。

單打／雙打、難度、場地、分數、局數和球衣顏色在按「開始比賽」之後選。

畫面與聲音

主動得分（殺球、切球、放網…打進對方場內，不算失誤、掛網、出界）時，播約 3 秒的慢動作特寫；點一下就跳過。
